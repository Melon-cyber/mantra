# Мантра

Карточки для запоминания с интервальными повторениями для Android. Без рекламы, без аккаунтов и без серверов: колоды и прогресс хранятся только на телефоне.

## Возможности

- Колоды со значком и цветом, карточки «вопрос — ответ» с примером или подсказкой.
- Интервальные повторения в духе Anki: новая карточка возвращается через минуту и через десять, потом через день, а дальше паузы растут с каждым верным ответом. Четыре кнопки «Снова / Трудно / Хорошо / Легко» показывают, когда карточка вернётся.
- Лимит новых карточек в день для каждой колоды, отмена последнего ответа.
- Добавление голосом: говоришь слово (или несколько через «and»/«и»), Мантра распознаёт его, сама переводит и показывает карточки для проверки. Можно говорить и по-русски — тогда переводит на изучаемый язык.
- Кнопка перевода в редакторе карточки, язык колоды (английский, немецкий, французский, испанский, итальянский, турецкий, китайский, японский, корейский).
- Добавление списком: строки «cat — кошка», «cat;кошка» или с табуляцией, в том числе из файла (подойдёт текстовый экспорт из Anki и Quizlet).
- После «Показать ответ» — значения слова по частям речи и примеры предложений с переводом (их тоже можно прослушать). Найденное сохраняется и показывается потом без интернета.
- Ответ на выбор для каждой колоды: перевод на русский или определения на изучаемом языке (английские дефиниции, как в толковом словаре).
- При вводе слова вручную Мантра сама находит перевод или определение и примеры: всё подставляется в карточку, а другие значения и примеры можно выбрать нажатием.
- Перевод с несколькими значениями («take» → «брать, взять, принимать»); если основной сервис не отвечает, используется запасной.
- Произношение слова голосом телефона: латиница по-английски, кириллица по-русски.
- Серия дней подряд, прогноз повторений на неделю, отметка «выучено».
- Готовая колода для пробы: 50 частых английских слов.
- Копия в файл и восстановление.

## Сборка

Нужны JDK 17+ и Android SDK 36. `./gradlew :app:assembleRelease`. Подпись настраивается файлом `keystore.properties` (не попадает в Git); без него используется стандартный отладочный ключ.
